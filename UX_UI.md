# UX and UI Specification

## 1. Design direction

The product should feel:

- calm,
- modern,
- academic,
- focused,
- premium,
- fast,
- and information-dense without being cluttered.

Avoid:
- childish language-learning visuals,
- cartoon mascots,
- excessive gradients,
- giant empty cards,
- over-animation.

---

# 2. Recommended layout

Desktop:

- left sidebar navigation
- central study workspace
- optional right context panel

Mobile:

- bottom navigation
- single-column cards
- sticky review actions

Recommended layout:

- passage

Right:
- questions

Controls:
- timer
- furigana toggle
- dictionary toggle

# 9. Quick clinical mode

This is important for hospital use.

A special compact mode should allow extremely fast lookup.

Example:

Search:
`胸痛`

Instant output:
- key questions
- dangerous red flags
- examination phrases
- test explanation
- simple patient explanation

Do not require navigating multiple pages.

---

# 10. Typography

Japanese readability is critical.

Recommended:
- Noto Sans JP
- system sans fallback

Reading passages:
- generous line height
- medium text width
- adjustable size

---

# 11. Theme

Support:
- light
- dark
- system

Optional accent color configurable.

---

# 12. Interaction principles

- search-first
- minimal clicks
- keyboard friendly
- preserve study context
- allow instant save to review
- never hide essential information behind unnecessary modals
